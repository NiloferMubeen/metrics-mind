💡 Key Message: Accuracy can lie when classes are imbalanced. This is why we need Precision, Recall, F1 and AUC-ROC.
Accuracy = (TP + TN) / (TP + TN + FP + FN)
= Correct Predictions / Total Predictions

✅ When Accuracy Works

When your dataset is balanced — roughly equal samples in each class. Example: classifying handwritten digits (0-9) with equal training examples.

❌ When Accuracy Fails

When one class dominates the dataset. A model predicting "No Cancer" for everyone gets 99% accuracy on a dataset with only 1% cancer patients.

🔑 The Dumb Baseline

Always compare against the "majority class baseline". If predicting the most common class gives 90% accuracy, your model needs to beat that meaningfully.

Module 02 — Confusion Matrix Detective Game

🔬 Precision & Recall

Two metrics that tell you what kind of mistakes your model makes — before you even see a formula.

🕵️ Confusion Matrix Detective Game

Think through which mistake is worse — before we introduce the formulas.

🏥 Scenario A — Cancer Detection

A model screens patients for cancer. It can make two kinds of mistakes:

😰
Mistake A
Predict cancer when patient doesn't have it (False Positive)
💀
Mistake B
Predict no cancer when patient actually has it (False Negative)
✅ Mistake B is far worse!
Missing a real cancer patient (FN) can be fatal. A false alarm (FP) just means an extra test. This is why we use Recall — catching all real positives matters most.
📧 Scenario B — Spam Detection

A spam filter marks emails as spam. Which mistake hurts more?

😤
Mistake A
Spam goes to inbox (False Negative)
😱
Mistake B
Important client email goes to spam (False Positive)
✅ Mistake B is worse!
Letting some spam through is annoying. Blocking a client's email can cost a deal. So we maximise Precision — only flag something as spam when we're very confident.
Precision = TP / (TP + FP)
Out of all PREDICTED positives, how many were actually positive?
💡
Think: When I cry wolf, how often is there actually a wolf? High precision = low false alarms.
Recall = TP / (TP + FN)
Out of all ACTUAL positives, how many did we catch?
💡
Think: Out of all actual wolves, how many did I detect? High recall = miss nothing.

F1 = 2 × (P × R) / (P + R)
Harmonic Mean of Precision and Recall
F1 ≠ (P + R) / 2
⚠️ Wrong! Arithmetic mean hides extreme values

Model A: Precision = 1.0, Recall = 0.0 → Arithmetic Mean = 0.5 ← Looks decent!

Harmonic mean punishes extremes — if either P or R is near 0, F1 collapses toward 0 automatically.

Module 04 — Classification Report Mystery

📊 Classification Report Deep Dive

Read a real report, spot what's misleading, understand Macro vs Micro vs Weighted averages.

🔍 The Mystery Report — What's Really Happening?

Study this real classification report output. Then answer the detective questions below.

classification_report(y_true, y_pred)
precision recall f1-score support
Class 0 0.97 0.99 0.98 950
Class 1 0.60 0.30 0.40 50
accuracy 0.96 1000
macro avg 0.79 0.65 0.69 1000
weighted avg 0.95 0.96 0.95 1000

No — it's deceiving you. The model barely ever sees Class 1 (only 50 out of 1000). It learned to mostly predict Class 0 and gets rewarded by accuracy. Class 1 recall is only 0.30 — it misses 70% of minority class cases. If Class 1 is fraud or disease, that's a disaster.

Macro Average gives equal weight to both classes. Class 0 F1 = 0.98, Class 1 F1 = 0.40. Average = (0.98 + 0.40) / 2 = 0.69. Macro is honest — it exposes that one class performs terribly.

Weighted Average multiplies each class F1 by its support: (950 × 0.98 + 50 × 0.40) / 1000 = 0.95. Class 0 has 950 samples and dominates the average. Weighted avg is inflated by the majority class — it hides minority class failure.

📌 What is "Support"?

Support = the number of actual samples in that class in the test set. It's your sample size per class. Low support means less trustworthy metrics — Class 1 with only 50 samples gives us less confidence than Class 0 with 950.

🏫 Classroom Analogy — Macro vs Micro vs Weighted

Imagine two sections. Class A = 900 students, Class B = 100 students. The model performs: Class A → 95%, Class B → 50%.

⚖️
Macro Average
(95 + 50) / 2 = 72.5%
Every class gets equal vote
📊
Weighted Average
(900×95 + 100×50)/1000 = 90.5%
Bigger class gets more votes
🌍
Micro Average
Pool all TP/FP/FN globally
Entire population votes together
🧠 Easy Memory Trick
AVERAGE THINK OF IT AS… USE WHEN…
Macro Every class gets equal vote Minority classes matter equally
Weighted Bigger classes get more votes Imbalanced datasets
Micro Entire population votes together Overall system performance
❓ Which average reveals minority class problems?
→ Macro Average — because it gives equal weight to the struggling minority class, pulling the overall score down.

FP / (FP + TN) — Out of all actual negatives, how many did we wrongly flag? X-axis of the ROC curve.
